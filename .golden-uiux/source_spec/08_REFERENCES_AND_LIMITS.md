# Source Register and Scientific Limits — NON-FINAL

These public references anchor individual requirements. The full licensed ISO standards were not copied or inspected in this package. Specific legal compliance can only be judged by the organization's authorized legal/security/product owners.

| Authority | URL | Supports | Does NOT establish |
|---|---|---|---|
| WCAG 2.2 Recommendation | https://www.w3.org/TR/WCAG22/ | Testable criteria and exceptions for web accessibility, e.g. 2.5.8 target sizing and spacing | The best visual brand, subjective aesthetics, law compliance in every jurisdiction |
| WAI-ARIA APG | https://www.w3.org/WAI/ARIA/apg/patterns/ | Keyboard/role/state conventions and exemplars for composite widgets | That custom ARIA is always best, or that a custom widget passes without testing |
| WAI-ARIA grid | https://www.w3.org/WAI/ARIA/apg/patterns/grid/ | Keyboard focus responsibilities in interactive grids versus ordinary tables | Requirement to use ARIA grid for all lists |
| WAI-ARIA combobox | https://www.w3.org/WAI/ARIA/apg/patterns/combobox/ | Popup semantics and keyboard behavior | Correctness of an untested implementation |
| Design Tokens Community Group 2025.10 | https://www.designtokens.org/tr/2025.10/ | Stable community token exchange schema and typing | W3C Recommendation or automatic accessibility compliance |
| ISO 9241-11:2018 | https://www.iso.org/standard/63500.html | Usability conceptual framework (effectiveness, efficiency, satisfaction) | Any universal optimal spacing or verified effect size |
| ISO 9241-210:2019 | https://www.iso.org/standard/77520.html | Human-centered design process and context of use | A completely automated guarantee of designer quality |
| ISO/IEC 25010:2023 | https://www.iso.org/standard/78176.html | Product quality model | A single valid numerical score for all designs |
| OpenCode agent skills | https://opencode.ai/docs/skills | Native discoverable SKILL.md syntax and on-demand retrieval | A working company installation without version and authorization inspection |
| Existing Golden Agentic Engineering Standard | https://github.com/kimhw8084/agentic-engineering-golden-standard | Existing engineering work loop, context/tool trust, evaluation, safe brownfield reuse | This module is already approved or validated in production |

**Caveats:** WCAG applicability is determined by the product and policies; `Target Size (Minimum)` contains exceptions. A project may impose stricter obligations. ISO is not represented as openly licensed text here.
