# Acceptance and limitations — mandatory distinction

**This archive is a working implementation candidate, not independently certified Golden quality.** The following evidence is deliberately separated:

| Capability | Evidence this deliverable may establish | Still requires the actual workstation or application |
| --- | --- | --- |
| Python runtime | Compiles; unit and stdio protocol tests can run offline | Python/runtime compatibility on your exact workstations |
| Installer | Reversible only for unchanged recorded files; refuses collision | Repo-level integration approval, file ownership, corporate policy |
| 14 pattern contracts | Catalog complete, retrievable and hash-bound | Correct UX decisions in actual app, including against 24 adversarial held-out cases |
| Nine skills | Valid-looking frontmatter and installed file locations | Discovery/loading and behavior with your exact OpenCode version/model |
| Project adapter | Structural validation and local digest check | Real source inventory, company owner approval, authenticity/expiry |
| Evidence audit | Rejects missing/stale records; refuses model self-certified promotion | Trusted CI, reviewer authentication and executable browser/AT checks |
| Geometry | Detects some declared numerical expansion | Actual DOM/browser measurements and approved baseline/tolerances |
| Minimum TAT | On-demand instructions, no network/runtime dependencies, cheap-first checks | Paired measured TAT including tool time, rework, review wait and defect escape |

**Hard required checks:** exact task grant and source revision, project profile with trustworthy authority, applicable WCAG 2.2 (plus stricter project rules), keyboard and real assisted-technology flows where mandated, tests and data integrity, geometry preservation or approved exceptions, independent risk review where required, CI/Git branch protections. The model, MCP, and this package never certify their own review.

**Evidence states:** `NOT_RUN`, `PASS`, `FAIL`, `BLOCKED`, `NOT_APPLICABLE`, `WAIVED`. `UNKNOWN` is a knowledge gap; it isn't PASS. `PASS` requires real source-bound external evidence. Waivers only when independent accountable authority explicitly permits them within law/company policy. A source diff does not automatically require retesting every unrelated check, but dependency-based reuse must be externally auditable.

**No guarantee:** performance and law-abiding compliance cannot be mathematically guaranteed for unknown code, incomplete requirements, flawed upstream tools, or subjective aesthetics. This package's maximum-quality design contract is falsifiable, not a verified perfect implementation. The correct behavior is to refuse unsupported claims and escalate only the affected decision.

**High-value next evaluation:** approved isolated SysGrid baseline first, followed by selected safe improvements, independent browser/keyboard/a11y checks, unmodified 44-rule SysGrid Constitution, protected Git PR routing, and at least one substantially different UI project. Pre-register TAT/quality metrics before comparing agent variants.
